## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "defillama": {
      "url": "https://gateway.pipeworx.io/defillama/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use defillama
```
